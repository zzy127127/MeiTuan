# 心屿 · 情绪日记与自我关怀

给情绪一个停靠的地方。

**在线体验：[https://zzy127127.github.io/MeiTuan/](https://zzy127127.github.io/MeiTuan/)**

心屿是一个无需注册的轻量网页产品，面向承受学业、职场和关系压力的年轻人。它把记录、回顾与一小段可以立即开始的关怀练习放在一起，帮助用户从“我现在不太舒服”走到“我可以先为自己做一点什么”。

## 为什么这样设计

| 用户的困难 | 对应的设计 |
| --- | --- |
| 想记录，但没有精力写长日记 | 选择情绪和舒适度即可保存；文字、生活因素、情绪强度与需要可以按意愿补充 |
| 记了很多，却不清楚哪些事情常与感受一起出现 | 提供近 7 天 / 30 天舒适度趋势、情绪分布、标签频次与具体观察 |
| 看过很多建议，依然不知道此刻做什么 | 根据自己的选择给出 3 个可解释的关怀方向，也可以按类型和可用时间自行选择 |
| 做过练习，却不记得哪种方式适合自己 | 记录实际练习时长、练习后舒适度和主观反馈，供之后回顾与推荐参考 |
| 不想为试用注册，也担心日记被公开 | 日记留在当前浏览器；不要求账号，提供个人数据备份与独立的虚构示例体验 |

## 约 60 秒体验核心流程

1. 在首页点击“体验示例故事”，查看虚构的一段生活记录及情绪洞察。顶部横幅会明确提示示例模式。
2. 切换“近 7 天 / 近 30 天”，观察舒适度、常见生活因素与练习反馈；点击“退出示例体验”回到自己的空间。
3. 选择一个情绪，调整独立的舒适度，勾选一个生活因素，保存。文字可以不填。
4. 查看推荐原因，开始一个练习；体验暂停与继续，数秒后可以“提前结束并记录”。填写反馈或跳过反馈后保存，再去洞察页查看记录。

以上是快速体验路径；正常练习可以按照标注时长完成。提前结束只记录实际练习时间，打开弹窗或取消不会被算作完成。

## 产品闭环

**记录 → 洞察 → 关怀 → 反馈 → 下一次更了解自己。**

- **今日心情**：6 种情绪；独立舒适度；可选的触发标签、文字、情绪强度与当前需要。文字中的关键词只提出待确认标签，用户决定是否采用。草稿在浏览器允许时自动保存。
- **我的日记**：按日期回顾、关键词搜索、情绪筛选、编辑、删除与即时撤销。日记可导出为 JSON 备份。
- **情绪洞察**：按近 7 天 / 30 天查看每日平均舒适度、情绪分布、生活因素频次和练习反馈；图表附逐日数据表。没有记录的日期留白，不跨空白日期连线，也不会据此推断情绪。
- **关怀空间**：按冥想、音乐、运动、书写分类，支持按 1 分钟 / 3 分钟 / 5 分钟筛选；每项练习包含步骤、计时和完成回顾。
- **练习反馈**：可以记录练习后舒适度，以及“舒服了一点 / 差不多 / 不太适合”；也可以跳过反馈。仅使用一小时内最近一次日记的舒适度作为已知的练习前参考，并不是现场测量。

### 六项可执行的关怀练习

| 练习 | 时长 | 实际交互 |
| --- | --- | --- |
| 1 分钟呼吸 | 1 分钟 | 跟随视觉圆圈轻轻吸气、慢慢呼气；不屏息，节奏不舒服时可恢复自然呼吸或停止 |
| 2 分钟感官着陆 | 2 分钟 | 按步骤留意周围的颜色、触感、声音与其他感官信息 |
| 3 分钟舒缓音乐 | 3 分钟 | 点击开始后播放本地生成的轻柔合成和弦，可调音量、暂停和停止 |
| 5 分钟散步 | 5 分钟 | 选择安全、熟悉的环境，按自己的节奏行走；不依赖定位或计步权限 |
| 2 分钟舒展 | 2 分钟 | 通过轻柔的肩膀、手臂与手指活动短暂休息，任何不适都可以停止 |
| 3 分钟自我关怀写作 | 3 分钟 | 根据提示写给此刻的自己；练习文本只存在于当前弹窗，退出清空，不自动写入日记 |

计时依据实际经过的时间，暂停期间不累计。结束或关闭练习会停止音频并清理计时；同一次练习只有在确认保存时才新增一条记录。

## 分析与推荐的边界

当前版本由 AI Coding 辅助实现，运行时使用**本地规则与统计，没有接入远程大模型**，不需要 API Key。日记内容不会被发送给外部 AI 服务。

推荐综合用户主动选择的情绪、生活标签、需要、情绪强度、舒适度，以及已有的练习反馈进行排序，并说明“为什么推荐”。反馈曾经好一些的练习可以获得适度优先，但用户始终可以选择其他方式。

舒适度是用户独立选择的 1–10 分刻度，与情绪种类、情绪强度分开。开心、平静、焦虑等情绪没有被排成心理健康高低顺序。平均值只使用有效的舒适度评分；没有评分的旧日记不参与均值。

标签与低舒适度同时出现，只能说明共同出现，不能证明因果。练习后的变化也是个人回顾，不表示某项练习必然有效。心屿提供日常记录和自助关怀，不做心理诊断，也不替代专业心理咨询或医疗服务。产品中提供了联系可信任的人、寻求更多支持的入口。

## 数据、兼容与示例隔离

- **本地保存**：个人日记、关怀记录和草稿保存在当前浏览器的 `localStorage`，使用 `mind-island-v2` 数据键；应用不收集分析埋点，也不将日记上传到公开代码仓库。
- **旧版兼容**：没有新版数据时，会读取 `mind-island-v1` 中的有效日记，并保留旧版关怀累计数。未记录舒适度的旧日记显示为未评分，不根据情绪自动补分。
- **独立示例**：虚构示例使用独立的内存数据。浏览、编辑和练习都不会改动个人日记；退出后回到个人空间。导出示例文件会带有示例标识，不能导入个人记录。
- **导出与导入**：在“数据与隐私”中导出或导入 JSON。导入先校验文件内容，再合并记录；重复 ID 跳过，不覆盖同 ID 的现有记录。支持不超过 5 MB 的备份文件。
- **保存失败**：浏览器禁用存储或容量不足时，界面会提示记录暂存于当前页面，应在离开前导出备份。
- **隐私限制**：本地数据和导出文件没有加密，使用同一浏览器的人可能看到日记。清理站点数据、关闭无痕窗口或换设备可能导致数据丢失；需要手动导出、导入，没有账号同步功能。

## 运行与维护

项目使用原生 HTML、CSS 和 JavaScript，无需安装依赖或执行构建。可直接打开 `index.html` 体验；日常使用和评审建议访问上面的 HTTPS 在线地址，以保持稳定的浏览器存储来源。

主要文件：

```text
index.html             页面结构、产品文案与辅助弹窗
style.css              主界面、移动端布局与可访问性样式
app.js                 路由、表单、日记、存储、导入导出与示例模式
engine.js              情绪与活动定义、推荐规则、统计和虚构数据
care.js / care.css     关怀练习弹窗、计时、音频与反馈
favicon.svg            站点图标
.nojekyll              直接发布静态文件
tests/engine.test.cjs  核心统计与推荐测试
```

在项目目录中运行：

```sh
node tests/engine.test.cjs
node --test tests/app.test.cjs
```

测试涵盖空数据、日期窗口、有效评分与未评分记录、标签计数、推荐依据、练习反馈等核心逻辑。它不替代浏览器验证；发布前还应实际检查保存日记、刷新保留、示例切换、练习暂停与完成、备份导入导出，以及手机布局。
