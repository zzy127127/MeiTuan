# 心屿 · 情绪日记与自我关怀

无需注册的轻量自我关怀产品。直接打开 `index.html` 即可使用，无需安装依赖。

- 今日心情：五种情绪、强度、触发标签与文字记录。
- 我的日记：浏览、搜索、删除与 JSON 导出。
- 情绪洞察：近七天情绪走势、触发因素频次与本地规则观察。
- 关怀空间：一分钟呼吸动画、可播放舒缓和弦、散步与舒展任务。
- 隐私：记录仅存当前浏览器 localStorage；清理浏览器数据会丢失，请导出备份。

此版本使用透明的本地规则分析，没有接入远程大模型，不提供心理诊断。

## GitHub Pages

将文件上传仓库根目录，在 Settings → Pages 选择 Deploy from a branch，分支 main，目录 / (root)，保存。部署完成后访问 https://zzy127127.github.io/MeiTuan/ 。后续保持仓库名称不变即可沿用网址。
